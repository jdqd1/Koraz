# Cobertura según la disciplina

Usa el patrón que explica la capacidad del tema; no impongas todos sus pasos si la guía no los sustenta. Para temas mixtos elige la disciplina predominante y registra la combinación en notas. La matriz de revisión debe vincular cada objetivo, afirmación de feedback y actividad a fragmentos concretos. No convertir una descripción en un diagnóstico o decisión terapéutica ausentes de la guía.

| Disciplina del contrato | Patrón para objetivos | Formatos pertinentes y límites |
|---|---|---|
| `anatomy` | Orientación → identificación → relaciones → aplicación topográfica. | Imagen revisada para identificación espacial, tabla/pares para relaciones, caso acotado para trayectos. Con `verb:identify`, falta de image_target produce `ASSET_REQUIRED`; conservar el objetivo y la incidencia, sin cambiar el verbo para eludirla. |
| `histology` | Organización → identificación microscópica → relación estructura-función. | Imagen real con escala/contexto, comparación de tejidos y aplicación de relaciones de la guía. `identify` necesita imagen revisada y alternativa, igual que anatomía. |
| `embryology` | Secuencia → transformación → relaciones entre etapas → consecuencias descritas. | Orden, comparación y predicción acotada. No inventar malformaciones/causas ni edades que la guía no aporta. |
| `physiology` | Variable → mecanismo → perturbación → respuesta/integración. | Tabla causal, secuencia, predicción de cambios o caso con datos de la guía. No añadir valores normales, unidades o fórmulas desconocidos. |
| `biochemistry` | Transformaciones → regulación → integración. | Secuencia/pares, mecanismo y respuesta a cambios descritos. No fabricar sustratos, enzimas, balances o deficiencias para completar banco. |
| `pharmacology` | Diana → mecanismo → efecto → diferenciación. | Tabla de discriminadores, secuencia y decisión limitada a la fuente. No introducir dosis, contraindicaciones o recomendaciones terapéuticas externas. |
| `pathology` | Normal → alteración → mecanismo → manifestación. | Comparación, causalidad y caso apoyado en fragmentos. Si hace falta imagen para la capacidad prevista, registrar su ausencia. |
| `clinical` | Problema → mecanismo → diferencial → discriminadores → decisión. | Caso progresivo, tabla comparativa, recuperación de criterios explícitos. Toda decisión/distractor clínico debe estar sustentado; contradicción bloquea ese contenido hasta revisión. |
| `general` | Concepto → relaciones → aplicación observable. | Seleccionar recuperación, elaboración y aplicación acordes al tema; no usar esta disciplina para evitar una exigencia visual de anatomía/histología. |

La representación debe cambiar la tarea: explicar en texto y aplicar en tabla/caso/diagrama respaldado por la guía puede medir relaciones; cambiar `representation` en una pregunta idéntica no crea transferencia. Un caso sintético puede combinar hechos ya sustentados sin añadir afirmaciones clínicas nuevas; indica su carácter didáctico y documenta qué fragmentos sostienen cada etapa.

Si faltan figuras, derechos o contenido, conserva la capacidad prevista en la matriz y las incidencias. La alternativa accesible evalúa una relación en otra modalidad, sin asegurar que mide idéntica capacidad espacial ni que reemplaza un gate espacial. No genera ni descarga imágenes para rellenar la falta de material revisado.
